## Protocol and limitations

- Seeds 404/505 used the existing GRU-64 Gold-Only training contract: 12 epochs, AdamW, batch 32, TRAIN-only feature normalization and class weights, minimum unweighted gold DEV_CAL loss checkpoint selection.
- EVAL-V3 `CAL_MAX_ERROR_MACRO_F1` thresholds were fit separately per system/seed on DEV_CAL only.
- For seeds 404/505 exact target and gap metadata values and order were checked across EXP-36, EXP-43, and matched student scores on DEV_CAL and DEV_SEARCH.
- DEV_SEARCH is development-exposed; five-seed means are descriptive, not confirmatory. No protected data were used.
