## 1. Inference contract and outputs

The intended inference claim is audio plus the intended canonical phone sequence; the frozen spec explicitly allows intended phonemes as alignment input. Do not consume manifest labels, realized phones, gold boundaries/timing, speaker identity, or speaker-specific priors. The H-002 extractor consumes `canonical_phones` and copies `target_X[:,:39]` from the FRAME_CACHE; it uses those phones for predicted monotonic forced alignment. Its feature receipt says no gold timing, realized phone or labels enter this extraction step. No actual prohibited-realized-phone/gold-timing leakage was found here. The upstream cache producer/dataflow and text-to-phone origin are not available in the reviewed receipts, so the stronger *raw audio + prompt text alone* provenance claim remains unverified. Four of 59,562 reference rows are intentionally all-zero UNKNOWN vectors: ABA_arctic_a0025::21 (ER)), BWC_arctic_a0434::28 (D_), SVBI_arctic_a0006::7 (SPN), HJK_arctic_a0104::4 (Z_). Retain those IDs/topology with explicit UNKNOWN/zero vectors; never silently map them to phone 0 or rewrite gold targets. The bounded lineage gate below applies only to the stronger prompt-text inference claim, not the operator-authorized intended-phoneme-conditioned scenario.

Per utterance with N intended phones, emit exactly N target scores and N+1 gap scores. Target classes are `CORRECT=0, SUBSTITUTION=1, OMISSION=2`; emit normalized three-way probabilities `(p_C,p_S,p_O)` and optionally raw logits. Gap index is `j=0..N` and predicts binary `has_insertion`; emit `p_I` at every gap including both edges. Stable joins are `(utterance_id,slot_idx)` and `(utterance_id,gap_idx)` (serialized `uid::index` only where unique within TRAIN). Full system AP-I uses exact-gap positives only. No gap-to-target warning assignment is inferred without a frozen policy.

## 2. Architecture decision

Choose **independently trained target and gap modules over the same frozen acoustic feature extractor** as primary; this is modular, not a shared trainable multi-head network. The target module predicts C/S/O from H-002 local acoustic features plus intended phone identity. The gap module predicts I on every N+1 boundary from adjacent acoustic contexts and intended-phone inputs, with explicit edge handling and no gold timing. Separate module parameters, losses and fitting receipts isolate target/gap imbalance and prevent one task's gradients from changing the other. A unified multi-head model is specifically a shared *trainable* acoustic trunk with two heads and is only a matched controlled ablation, because insertion transfer from target is unvalidated. A staged design (target model predictions fed to a separate gap stage) is also an ablation only; it can transfer target-model errors and needs complete OOF base predictions. The primary is the simplest independently auditable modular design. Keep MB03 frozen PLAIN as mandatory insertion comparator and MB07 direct/fixed/meta methods as S/O references, not replaceable baselines.

One acoustic material family only: the frozen H-002 layer-6 hidden-state representation currently used in the dataset, conditioned on intended canonical phones as explicitly allowed by the frozen contract. The feature producer is ASR-finetuned Wav2Vec2 Base 960h, hidden_states[6], 20-ms frame period, local crop centered at predicted phone center via monotonic Viterbi against canonical phones; receipt says no gold timing, realized phone, or labels enter extraction. This is not untouched self-supervised pretraining. Before claiming raw audio+prompt-text-only inference, pass the bounded text-to-phone lineage check: inspect/hash the FRAME_CACHE creator and cache index, prove canonical phones/reference come from `prompt_text` via fixed lexicon and not annotation-derived realized/timing fields, match all 59,562 intended phone slots and encodings (explicitly retain the four identified UNKNOWN zero vectors: ABA_arctic_a0025::21 ER), BWC_arctic_a0434::28 D_, SVBI_arctic_a0006::7 SPN, HJK_arctic_a0104::4 Z_). Failure blocks that stronger prompt-only claim, not the intended-phone-conditioned study if canonical intended input itself is authorized. The current evidence establishes no prohibited realized-phone/gold-timing leakage. Do not substitute frame alignment features that depend on gold timing.

## 3. Outer and inner fitting contract

Official outer folds are speaker-held-out, exactly: F0 ABA/ASI/BWC; F1 EBVS/HJK/HKK; F2 HQTV/LXC/NJS; F3 PNV/SKA/SVBI. For each outer fold, fit transforms/models only on its other nine speakers; held outer speakers are absent from every fit. Use fixed final epochs (target module 12, gap module 5) with no validation checkpoint selection, avoiding repeated selection against reused inner validation labels. These are predeclared schedules from existing direct C/S/O and PLAIN gap recipes, not values selected from MB08 outcomes. Save only final-epoch checkpoints. If those budgets fail a pre-run CPU timing pilot, amend both uniformly before any outer scoring and document the pre-outcome change; do not tune epochs on held-out outcomes. For inner joint-policy calibration only, obtain eligible OOF base scores by holding out each of the three groups of those nine speakers and fitting each module on the remaining six; normalization is from those six only. Outer test labels are consumed after all outputs and deployment thresholds are frozen. No per-speaker fit or same-speaker train/validation overlap.

Fold-only normalization: feature means and population standard deviations (`ddof=0`) from that model's fit speakers only; clamp std below at `1e-4`; apply unchanged to its validation/test. No global TRAIN statistics. Seed Python, NumPy, and torch; seed-specific fold seeds are `base_seed + outer_fold*100 + inner_fold` for inner fits and `base_seed + outer_fold*100 + 90` for outer refit. Primary `101`; replication `202`; diagnostic seed `303` only after primary/replication artifact integrity and if <=45-min lane budget. Deterministic CPU algorithms where supported, record library versions, worker/thread counts and nondeterministic operations.

## 4. Objective, balancing and updates

Use separate mean-reduced weighted cross entropy for independently trained modules. Target class weights use the current fit partition only: `w_c=sqrt(N_fit/(3*max(n_c,1)))`, divided by their arithmetic mean. Target loss is `sum_i w[y_i]*CE_i / sum_i w[y_i]`. For binary gaps use `w_I=sqrt(n_negative/max(n_I,1))`, `w_0=1`, then the same normalized weighted-mean formula. Weights use fit speakers only; no oversampling that changes OOF prevalence/test priors.

Train each module separately with AdamW, learning rate `8e-4`, weight decay `1e-4`, batch size 256, target final epoch 12 / gap final epoch 5, gradient norm clip 1.0. Each is a small standalone MLP on the frozen cached acoustic features; no shared trainable encoder in primary. Preserve all events and seeded shuffled batches. Do not select a best checkpoint on held-out/OOF labels; use final epoch only. Feature arrays are memory-mapped; cap process RSS at 4 GiB, load one module at a time, minibatch <=256, no device copies/CUDA. CPU lane cap <=45 minutes per outer-fold/seed pipeline. Any timing amendment changes fixed epoch counts uniformly before outcomes. If still over budget, stop rather than prune folds/seeds.

## 6. Threshold policy and nested calibration

AP has no threshold. For joint operational policies, obtain exact-ID target and N+1 gap OOF predictions and labels from outer-training speakers. Target warning confidence is `max(p_S,p_O)` and class is `argmax(p_S,p_O)`; gap confidence is `p_I`. Search all distinct target/gap score breakpoints and tie groups on inner OOF only. A target false warning under EVAL-V3.1 is **any predicted S/O unequal to gold** (including wrong S-versus-O type, counted in `FP_S+FP_O`); a gap false warning is predicted I on a gold-negative exact gap. Joint FWR=`(FP_S+FP_O+FP_I)/n_unique_utterances`, not gold-C-only binary FP and not total alerts. For each frozen budget `.2,.5,1,2`, select threshold pair subject to joint FWR<=budget maximizing lexicographically O recall, S recall, I recall, then fewer total alerts; deterministic event-ID hash breaks remaining ties. Search inner-only; denominator is unique inner-training-pool utterances and includes both domains. Freeze both thresholds and apply unchanged to outer. Report achieved outer joint FWR, target and gap FP components, total alerts/utterance, classwise target and gap P/R/F1. If no candidate qualifies, select no-warning thresholds and record this. Outer labels cannot choose policies or interpolate/fabricate exact matching.

Do not fit learned fusion policies to the three outer-pool inner OOF blocks using ordinary second-stage crossfit: MB07 `fit_cross_meta` meta-held samples are scored by inner base models whose training speakers include the meta-held speakers. It is outer-fold-valid (outer speakers are absent from every fit) but not strictly inner-generalization-valid for selecting a threshold or claiming inner calibration. Phase01 default is fixed predeclared arithmetic fusion and no learned meta policy. If learned meta is included as exploratory, create strict crossfit meta predictions whose *entire base pipeline* excludes the meta-held speakers; reserve independently cross-fitted predictions for threshold selection. Otherwise label its fitted policy ineligible for deployment selection. Do not calibrate on outer labels.

Use `research/evaluation_v3/evaluator.py` (`UnifiedEvaluatorV3`, version EVAL-V3.1), stable event IDs, and canonical TRAIN manifest gold. Common-support interpolation of already-frozen outer policy curves is descriptive only, with support range, never a threshold/policy. Policy should prioritize robust low-FWR omission recall, then fold/speaker robustness and simplicity; AP is secondary. Report per-fold and per-speaker estimates with positive denominators, paired seed effects, and uncertainty via speaker-level resampling if performed. A pooled metric cannot hide a fold collapse.
