Population is TRAIN only: 1,800 utterances, 12 speakers, 59,562 target slots (S 7,381; O 1,825), 61,362 exact gaps (I 560). ## Primary hypotheses and comparisons

1. **Insertion.** A genuinely learned reference-conditioned monotonic audio alignment with optional explicit gap states improves exact-gap localization over the MB03 direct neural grouped OOF baseline (AP-I .162125; P@560 .24286). Primary seed 101, four outer folds; seed 202 replication only if feasible. Main ablation removes gap states while retaining comparable acoustic encoder, training data and folds. Acoustic-dependence control removes or shuffles acoustic information. Report pooled and per-fold AP-I and P@560; no claim of general alignment failure if this implementation loses. Preserve MB03 baseline on failure.
2. **S/O.** E4 supplies complementary evidence beyond direct H-002 at matched realized false warnings per utterance. Compare direct H-002, historical MB03 PLAIN, E4-only, fixed neural+E4, learned neural+prior+E4, neural+prior controls, and learned neural+E4 without prior if feasible. Seeds 101/202; four outer folds. Freeze policies using eligible inner OOF only at nominal 0.2, 0.5, 1, 2 warning budgets; compare actual realized FWR and classwise P/R/F1. Primary policy is selected by held-out operating performance and robustness, with AP as secondary ranking evidence. No outer-test labels in threshold selection.
3. **Training architecture.** Independently check mapping, splits, artifact hashes, acoustics and nested fit. Compare unified multi-head, modular and staged designs using existing evidence and compute limits. A ready design requires explicit target C/S/O and N+1 gap contracts, losses, seeds, class balancing, checkpoint selection, ablations, GPU lease or CPU plan, and EVAL-V3.1 metrics.

## Stopping and decision rules

Run one material alignment architecture with only the stated ablations; no broad hyperparameter sweep. Reuse verified completed artifacts. No formal unified training. A new insertion model is adopted only if it beats the MB03 baseline on pooled AP-I and P@560 without a fold collapse or failed leakage/acoustic control; otherwise retain MB03. S/O primary method requires valid nested provenance and practical matched-FWR behavior; choose simpler fixed fusion if learned fusion's operating benefit is not robust. GO requires valid evaluation, reproducible methods, complete design and feasible training. CONDITIONAL_GO permits a valid insertion baseline with bounded integration/calibration work. NO_GO requires material leakage, event mapping failure, irreproducible central evidence or absence of a valid training/evaluation design. Report missing full-system metrics explicitly.
