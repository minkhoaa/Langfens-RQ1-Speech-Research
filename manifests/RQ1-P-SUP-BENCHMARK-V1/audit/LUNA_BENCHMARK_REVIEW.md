- **Correct:** Protocol Z runs an audio-plus-written-prompt forward pass through `ZeroOracleL2ArcticDataset`, and the TextGrid read/alignment occurs afterward ( `audit_scripts/benchmark_psup_v1.py:944–1007`; `src/langfens_prep/dataset.py:290–297, 356–380`). - **Finding — P1: The reconciliation matrix labels Protocol O metrics as Protocol Z.** `run_model_inference_benchmark` assigns `benchmark_metrics = proto_o_metrics` at `benchmark_psup_v1.py:1032`; `generate_comparative_reconciliation_matrix` then labels those top-level metrics `Z-PROMPT-V1` and “Full N=9,956” at lines 1261–1284. The saved `reconciliation_matrix.json` consequently labels B-CONTROL fixed-budget’s 9,956-token O metrics (`binary_ap=0.322633`) as Z, while its actual saved Z metrics are for 9,919 aligned tokens (`binary_ap=0.316196`). **Smallest fix:** build separate matrix rows from `protocol_o` and `protocol_z` metrics with their actual protocols and cohort sizes; do not label O results Z.
- **Finding — P1: SELECT-best update counts are recorded as 3,600 regardless of actual checkpoint update.** The `t_op_best` and `b_control_best` configurations both hard-code `successful_updates: 3600` (`benchmark_psup_v1.py:142–144, 184–186`), and the manifest builder copies that value (`1197`). This contradicts the supplied checkpoint accounting: T-OP best is update 2,700 and B-CONTROL best is update 2,250. **Smallest fix:** use the checkpoint’s verified update metadata for each endpoint; report those actual values in the manifest and summary, not the fixed-budget count.
- **Finding — P1: The inference manifest does not attest to the saved Protocol Z artifacts.** The live inference manifest’s `out_files` at `benchmark_psup_v1.py:1108–1113` hashes only top-level metrics, operating points, offline evaluation, and runtime predictions; it omits the separately written `protocol_z/` predictions, evaluations, and metrics, as well as utterance predictions. The saved manifests’ `output_hashes` likewise do not list these files. **Smallest fix:** include every saved output in the manifest hash inventory, including protocol-specific files and utterance predictions.
- **Finding — P1: Manifest source hashes are fabricated constants, not hashes of the executing dependencies.** `generate_benchmark_run_manifest` hashes fixed byte strings (`hashlib.sha256(b"benchmark_psup_v1")`, etc.; lines 1174–1179), rather than reading source files. The saved manifest contains plausible file hashes that this implementation cannot produce. The manifest also omits hashes for inference-critical dataset, G2P, alignment, and TextGrid parser code. **Smallest fix:** compute hashes from the exact source and dependency files used at runtime, and include the Z data/alignment dependencies. Until regenerated and verified, the manifest cannot establish reproducibility provenance.
- **Finding — P2: The cyclic-control gap is calculated against a hard-coded historical AP, not the current run’s matched predictions.** At `benchmark_psup_v1.py:925–927`, mismatch AP is subtracted from `config_info["reported_metrics"]["binary_ap"]`. That value is a configured historical result, not the live run’s matched Protocol O or Z AP. **Smallest fix:** compute the matched AP from the corresponding saved live predictions and compare it with the mismatch scores for the same protocol and cohort; otherwise mark the gap unavailable.
- **Finding — P2: Preparation documentation overstates results and misstates the operating-point arithmetic.** `COMPARISON_AND_RECONCILIATION.md:74–95, 103–114` calls the results reproduced and makes a conclusive scientific claim, although the available raw Z artifacts cover aligned 9,919-token cohorts and do not justify full-population Z claims. Its stated T-OP full-cohort recall-at-FPR15 of 0.724138 corresponds to 105/145; the supplied independent archival verification specifies 106/145 = 0.731034. **Smallest fix:** retract or correct the affected claims and threshold count, and present archived O, reproduced Z-aligned, and any still-pending output as distinct statuses.

Some inference artifacts are present, including Protocol Z outputs for fixed-budget configurations, but the matrix conflates protocols and manifests misstate endpoint accounting and omit or misrepresent provenance.
