# P-SCORE implementation readiness and handoff

Date: 2026-11-03. Scope: additive standalone scoring prototype and synthetic CPU forward-only checks. This is **implementation readiness only**, not scientific/performance PASS and not authorization for corpus/cache inference.

## Delivered

- `src/langfens_prep/p_score/ctc.py`: independently implemented log-space CTC forward probability and target activation-occupancy reward pass; canonical and per-position S / SD union output-language alternatives. Union alternatives are deduplicated by output string and summed once. Graph identifier `ctc-union-language-v1`. All 39 nonblank classes are alternatives; no next-neighbor exclusion. Deleting a target creates adjacency and repeated equal neighbors still require an intervening blank. Blank remains only the CTC blank, never a deletion class.
- Method identity is deliberately qualified: this is an independently authored published-formulation variant, **not** parity with unpublished/unresolved author implementation. Raw score is `log P(relaxed)-log P(canonical)` (higher means larger relaxed mass / error-oriented ranking). Exact posterior expected target-state visit count and its `max(1, occupancy)` division are separately named auxiliary output, not the paper's Eq. 13 approximation. SDI is rejected/unsupported. Infeasible/zero mass and no-frame cases abstain; invalid/nonfinite input fails closed.
- `controls.py`: greedy CTC collapse-before-blank-removal plus fixed deterministic Levenshtein; edit output explicitly indicates recognition mismatch, not human MDD label. Canonical self-aligned activation-average GOP is its own named control and does not claim physical localization.
- `runtime.py`: finite-value exact schema, phone/position identity, nested gold/perceived/timing/operation rejection, sealed speaker rejection, complete prompt-position accounting, and explicit failure/abstention values.
- `cache.py`/`cli.py`/`audit_scripts/p_score_infer.py`: provenance and config/hash gates, duplicate-key/nonfinite JSON rejection, synthetic namespace mode, frozen-cache only behind a separately hash-pinned authorization object and frozen split metadata; no audio/model/weight loader exists. No real cache was read. CLI produces source/config/cache/output hashes and provenance but does not certify source identity, actual weights, private storage durability, author parity or scientific validity merely by emitting hashes.
- Synthetic test coverage compares exhaustive tiny-lattice enumerations to independent acoustic-path enumeration, including repeats, boundaries, deletion, occupancy, zero mass, no frames/padding, long log-space sequence, controls, cache/runtime guards and an end-to-end synthetic CLI bundle.
