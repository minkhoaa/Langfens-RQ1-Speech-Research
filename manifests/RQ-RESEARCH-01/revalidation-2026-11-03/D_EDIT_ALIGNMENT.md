## Method comparison

| Method | Operation semantics / identifiability | Required supervision and acoustic confidence | Feedback/integration and cost |
|---|---|---|---|
| Fixed-target CTC Viterbi / forward-backward | Every canonical target label must occur in a valid CTC path; blank permits frames between labels, not a deleted target. Can score competing phone evidence, but cannot represent target omission without changing target/path model. | Transcript/reference phone sequence and acoustic emissions; no phone timestamps required. Posterior is conditional on target; blank may reflect silence, weak phone, boundaries or alignment ambiguity. | Strong low-cost comparator/reuse existing CTC head. Dynamic programming modest versus encoder; no calibrated deletion claim. |
| Monotonic attention / MoChA | Constrains progression/attended chunks; canonical slots still exist. Does not itself permit phone non-realization or explicit substitution/deletion. | Phone sequence plus acoustic frames; optional alignment supervision helps but not needed at inference. Attention weights are not correctness calibration. | Replace/add alignment module; inference/training cost higher than unconstrained dot attention but modest vs backbone (unmeasured). Better order prior; short/repeated phones remain ambiguous. |
| Skip/null attention graft (E1) | Null key offers one no-frame-like destination but does not encode edit path, ordering transitions, or distinguish omission from weak evidence. | Existing binary labels do not force skip posterior to mean omission. E1 skip mass empirically collapsed. | Minimal existing seam; small inference overhead. Feedback only as abstention cue after validation/calibration, not diagnosis. |
| Explicit pair-HMM / edit lattice / WFST | Epsilon deletion can advance canonical reference without phone emission; alternative-phone emission represents substitution; extra emission represents insertion. Transposition generally multiple edits. Repeated phones/confusables produce competing paths. | Operation labels or carefully specified weak supervision needed to identify transitions; without them deletion vs weak/short realization is confounded. Marginal path posteriors can express uncertainty, conditional on model. | Most semantically aligned; new transitions/DP and calibration, moderate engineering/training cost. DP roughly time×states; GPU cost unmeasured. Best pilot candidate only if label audit and controls support identification. |

## Direct primary literature / implementation inspection

1. **Graves et al., “Connectionist Temporal Classification: Labelling Unsegmented Sequence Data with Recurrent Neural Networks,” ICML 2006**, primary paper PDF [Toronto author copy](https://www.cs.toronto.edu/~graves/icml_2006.pdf), HTTP 200, PDF fetched and inspected. The paper’s CTC path mapping collapses repeated labels and removes blank; likelihood sums paths mapping to the target sequence. This supports the fixed-target constraint: blank is a frame-level path symbol, not an epsilon that skips a target label. Limit: generic sequence labeling, not deletion-specific pronunciation diagnosis. Code/checkpoint/license: no original implementation or license verified in this audit; Langfens has local CTC implementation in `src/langfens_prep/model.py`.
2. **Raffel et al., “Online and Linear-Time Attention by Enforcing Monotonic Alignments,” ICML 2017 (arXiv:1704.00784)**, [arXiv PDF](https://arxiv.org/pdf/1704.00784), HTTP 200, PDF fetched and inspected. Abstract/intro describes MoChA adaptively splitting input into chunks with soft attention, trainable by standard backpropagation and online linear-time decoding. It is a monotonic attention mechanism, not an edit model; no intrinsic omission state. Paper is speech translation/sequence transduction, not deletion-specific MDD. Implementation: the paper’s algorithmic formulation is inspectable; original code URL/license/checkpoint were not verified—do not claim availability or license.
3. **Baevski et al., “wav2vec 2.0: A Framework for Self-Supervised Learning of Speech Representations,” NeurIPS 2020**, [arXiv PDF](https://arxiv.org/pdf/2006.11477), HTTP 200, PDF fetched and inspected. Supports use of pretrained contextual acoustic representations as input evidence, not an edit-aware alignment mechanism or omission-specific performance claim. Model implementation/checkpoint public status is known generally but not inspected for this report; license/checkpoint revision not newly verified.

**Speech-MDD edit-alignment source limitation:** A direct search via Crossref/OpenAlex identified candidate primary publications (e.g. 2020 Interspeech “An Effective End-to-End Modeling Approach for Mispronunciation Detection,” DOI `10.21437/Interspeech.2020-1605`; 2021 “Mispronunciation Detection and Diagnosis for Mandarin Accented English Speech,” DOI `10.1109/SPED53181.2021.9587408`; 2025 phonological wav2vec2 MDD, DOI `10.1016/j.specom.2025.103249`). Attempts to retrieve the guessed ACL Anthology URL for the 2020 paper returned 404; no paper text or repository was verified. They are not used as evidence. No primary speech-MDD source explicitly implementing probabilistic edit/epsilon alignment was directly inspected; this is a remaining gap, not evidence that none exists. E1 is the verified local implementation comparator.

## Shortlist and bounded falsifiable pilot proposal

**Shortlist:** (1) fixed-target CTC forced alignment as comparator, not omission solution; (2) monotonic/MoChA order constraint as ablation, not skip; (3) explicitly supervised/weakly supervised edit lattice as strongest conceptual candidate, conditional on identification; (4) do not roll out E1 skip graft as-is given negative Fold1 archive result.

A future, separately authorized pilot should freeze Baseline R and evaluate Fold1 train/validation only; no TEST, no TextGrid interval as inference input. First run evaluation-only comparisons using identical checkpoint/emissions: standard CTC forced alignment, monotonic attention, E1 skip state, and explicit edit-state DP. Training a new edit head requires explicit authorization/separate config and remote compliant compute. Use true canonical targets vs realized labels and operation direction; report deletion AP, recall at fixed FPR, substitution scores, calibration/reliability, abstention, and results stratified by duration, boundary uncertainty, repeated phones, word-final coda and confusable class. Validation is used for checkpoint/threshold/calibration selection, so report selection leakage and avoid calling those estimates independent; preserve frozen baseline and paired speaker-level uncertainty. Falsify candidate benefit if deletion gain vanishes at matched FPR, is explained by phone duration/boundary shifts, or skip/edit posterior fails calibration. Gold intervals may be offline diagnostic labels only.

## Residual risks / confidence

CTC blank is not true deletion; hard Viterbi paths hide ambiguity. Canonical-vs-realized target direction and insertion/deletion alignment conventions can invert labels. Short phones (E1 coverage facts: many deletion intervals are short in archived report) and boundary uncertainty can make absence indistinguishable from weak acoustic evidence. Edit-state likelihoods may absorb reduced duration, silence, coarticulation or confusable substitutions; operation label quality and speaker generalization matter. Confidence high for local implementation semantics, thesis scope and E0/E1 archived provenance; moderate for CTC/MoChA mechanism interpretation from inspected primary papers; low for speech-MDD edit-lattice comparative ranking and GPU cost. No sealed TEST, audio/labels, source code edits, tests, training, backward pass, or optimizer execution in this work.
