## 3. Method comparison

Costs are relative design estimates, not measured LANGFENS runtimes or GPU timings. “No task training” still requires a pretrained encoder and permitted encoder inference. Feedback should be withheld unless acoustic evidence, target alignment and calibrated uncertainty agree.

| Method | Substitution vs deletion operation / identifiability | Actual supervision / acoustic evidence & feedback | Integration and cost; risks |
|---|---|---|---|
| **A. PER-MDD frame embedding retrieval** | Frame query retrieves labeled phone exemplars; supports realized-phone alternatives/substitutions. A deleted phone yields no phone-like frame to retrieve. Sequence edit alignment can infer a canonical deletion from missing output, but is indirect and confounded by ASR blanks, alignment errors and neighboring-phone context. | Tu et al. use frame-level aligned phoneme labels in the reference pool, not a deletion classifier. Similarity is a local acoustic score. Could show “this segment resembles /T/ more than expected /D/” only with a validated contrast and references; cannot claim high-confidence absence from no nearest neighbor without a calibrated reject policy. | Frozen encoder + cosine top-k index; no task-specific optimizer. At deployment each user utterance entails encoder compute plus nearest-neighbor lookup. Storage scales with indexed frames (mid-frame lowers it); build stores **per fold from TRAIN only**. More references improve coverage but increase accent/speaker leakage, storage/license and search cost. No indexed phone / novel realization → abstain. |
| **B. Phonological/articulatory attribute stream (SCTC-SB or attribute classifiers)** | Attributes can characterize phonetic substitutions (e.g. place/voicing) and near-miss pronunciations. A truly absent phone can manifest as no expected attribute sequence, but detecting it needs canonical-to-realized sequence alignment; shared blank represents CTC alignment slack, not deletion truth. | Shahin & Ahmed use 35 non-mutually-exclusive attributes with separable CTC/shared blank and mapped canonical feature targets; requires labeled attribute/phone sequences or derived labels and model training. Enables potentially intelligible “voicing differs” feedback; does not guarantee language-learner error confidence. | Additional output head/CTC objective and temporal decoder; train cost moderate/high, encoder fine-tuning in paper. Transfer to the frozen 40-class CTC/Binary contract would be a separate architecture/config and needs authorization. Attribute ontology has mapping collisions/phonological variants; absences in attribute output still require sequence-level diagnosis. |
| **C. Reference-audio/TTS template comparison** | Compare expected phone acoustics with matched prompted reference/local segment; strong concept for substitutions if same phone/context and temporal location are reliable. Absence is only indirectly indicated by a gap/short transition relative to expected realization—silence, coarticulation and weak release can mimic deletion. | Can use human reference recordings and forced/CTC alignment; TTS offers generated canonical targets but no L2 error labels by itself. Acoustic distance/likelihood is evidence, not correctness probability. Feedback can contrast learner/reference audio or play model audio. | New reference bank and alignment/scoring path. Per-utterance inference medium; reference acquisition/storage and speaker/prosody/domain mismatch high unmeasured cost. TTS voice differences can dominate distance. Require several licensed reference variants and explicit no-reference/low-confidence abstention. |
| **D. Canonical lexicon/rule prior + sequence edit/deletion detector** | Compare canonical target sequence to CTC/retrieval recognized sequence; substitutions/deletions are explicit edit operations. A deletion is a **sequence-level residual** when no realized phone maps to a target; it does not identify absent acoustics at a time point without local evidence. | Uses written prompt→G2P/lexicon canonical phones plus pretrained ASR/CTC outputs. No new label supervision if existing recognizer is reused; thresholds/phone-position priors require validation calibration. Feedback can identify “expected /t/ not reliably heard,” not claim a physical articulatory cause. | Lowest integration cost; reuse `g2p.py`, alignment utilities and CTC output. Very low added compute. High sensitivity to G2P variant and DP tie-breaking; common/position priors can create false alarms or leak validation labels. Canonical reference must be separated from expected *realized* variation. |
| **E. Calibrated hybrid: acoustic MDD + retrieval/attribute support + abstaining rules** | Binary error proposal identifies candidate; sequence residual proposes deletion, local acoustic score distinguishes likely weak realization from mismatch, retrieval/attributes explain substitutions. Absence is still not point-identifiable from blank alone; require convergent cues and uncertainty. | Existing supervised binary labels (sub/deletion) + per-phone/position labels and train-only exemplars; validation-only calibration. Feedback hierarchy: observed mismatch → competing phone/attribute evidence → tentative deletion warning → retry/abstain. | Highest integration/evaluation burden, inference cost sum of components; task head stays current only if components are inference-time scores. Any learned fusion is new training/config requiring authorization. Potentially best product alignment, but unmeasured; prevent score leakage and correlated evidence being double-counted. |

### Operation direction, confidence and leakage checks

Distinguish canonical target `c_i` from realized sequence `r_j`. For substitutions, an acoustic frame can support a competing phone/attribute. For deletion, there is no deleted-phone acoustic vector: the evidence is absence in a time span/sequence after aligning **surrounding realizations** to the canonical string. A Viterbi blank or retrieval threshold rejection also occurs in ordinary inter-phone silence, low SNR and unknown sounds. Thus `blank → deletion` is not identifiable without context and calibrated controls. Conversely, forced-aligning every canonical token onto speech can manufacture a token window and hide deletion. Gold TextGrid boundaries may label training/evaluation, never be inference input.

Retrieval stores must exclude validation/test speakers and utterances for that fold; even validation threshold selection must not be re-reported as independent evaluation. Freeze encoder/model and all baseline settings. A single global cosine threshold or per-phone score normalization estimated on the same validation tokens leaks calibration. Prefer nested speaker-held-out calibration if available; with only two Fold-1 validation speakers this is severely limited. Report raw ranking AP and separately calibrated operating point/FPR, with bootstrap clustered by speaker. Short phones (~few frames), boundary jitter and label ambiguity make both retrieval and GOP scores unstable; expose duration and boundary-stratified results and abstain.

## 5. Shortlist and minimal falsifiable pilot designs

**Research shortlist (not empirical rank):** (1) small train-only retrieval probe for substitution evidence and calibrated reject/coverage; (2) canonical-sequence residual plus local acoustic/CTC evidence as an explicit deletion-vs-blank test; (3) phonological attributes for specific substitution feedback, as a later independently authorized training configuration. Reference audio/TTS is a complementary product direction, not first pilot: reference-quality diversity and calibration costs are unmeasured. A hybrid should follow only if single cues demonstrate independent validation value.

**Common protocol for all pilots:** use only Fold-1 train/validation speakers (2,399 train / 300 val by contract), keep TEST sealed, freeze Baseline R checkpoint/config and greedy CTC path, no changes to existing objectives/checkpoints. Train any retrieval index only from Fold-1 TRAIN labeled examples; query validation only. No gold TextGrid timestamps at runtime. Compare on identical validation canonical positions; primary omission AP and recall at FPR≤15%, substitution AP, full binary AP, CTC PER; report omission prevalence, precision/recall/FPR, abstention/coverage, confidence calibration (Brier/ECE), short-phone and word-final strata. Cluster bootstrap speakers and disclose only two validation speakers. Set thresholds on an isolated calibration split or label any validation-tuned operating point exploratory; do not tune and score on same rows and call it held-out. Baseline must be rerun only if separately authorized; archived baseline numbers are reference, not parity proof.

- **Pilot 1: PER retrieval, no learning.** Construct mid-frame train index, compare cosine kNN vote with existing greedy CTC/Baseline R on the same validation tokens; pre-register k and similarity threshold (paper defaults k=10/τ=.7 as candidate, not assumed optimum). Report per-token coverage and phone confusion. Falsifier: retrieval fails to improve substitution ranking over a phone-prior/CTC control, or ostensibly low-neighbor “deletions” occur equally on correct low-energy/boundary frames. Deletion AP cannot be claimed from frame retrieval alone; sequence edit deletions must be separately evaluated against labels.
- **Pilot 2: deletion identifiability.** On validation only, compare: CTC sequence edit residual; CTC blank posterior over neighboring time spans; local GOP/phone score from forced alignment; and simple duration/energy/rule baseline. Gold intervals are targets only for offline diagnostic stratification, never model features. Use matched correct same-phone/speaker/position duration controls, count unmatched cases, exclude any selection-dependent AP claims. Falsifier: blank/GOP/duration cues fail to separate deletions from matched correct phones at fixed FPR or gains disappear with boundary jitter/short-span controls. This is an inference-only evaluation proposal; future causal masks/training need separate authorization.
- **Pilot 3: attribute explanatory head.** If Pilot 1/2 reveal residual substitutions where feature-level explanation matters, derive 35 attributes from canonical and labeled realized phone mappings on train only; train a separately authorized head/config, evaluate feature disagreement and phone-pair diagnosis on validation, and retain current baseline. Falsifier: attribute predictions fail to improve known confusion-pair diagnosis or calibrated feedback specificity over phone labels; no deletion benefit should be expected absent a demonstrated sequence skip mechanism.
