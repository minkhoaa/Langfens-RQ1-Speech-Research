## Primary external evidence

- Cao et al., [A Framework for Phoneme-Level Pronunciation Assessment Using CTC](https://www.isca-archive.org/interspeech_2024/cao24b_interspeech.html), Interspeech 2024. Genuine CTC path marginals support alignment-free sequence/edit scoring; current CharSiU frame-classification outputs are not interchangeable with them.
- Parikh et al., [Enhancing GOP in CTC-Based Mispronunciation Detection with Phonological Knowledge](https://www.isca-archive.org/interspeech_2025/parikh25_interspeech.html), Interspeech 2025. Restricts competing-phone alternatives using phonological clusters/common confusions; LANGFENS H04 directly tests whether TRAIN-derived constraints add acoustic S ranking beyond unrestricted alternatives and priors.
- Sara & Chowdhury, [Light-weight Pronunciation Assessment via Discrete Speech Token Surprisal](https://arxiv.org/abs/2606.19910), 2026. Describes native token sequence surprisal and transcript-guided Text2DUnit-DTW; the local unigram/bigram screens are inspired adaptations, not reproductions.
- Geng et al., [Subphonetic Acoustic Modeling via Optimal Transport for Pronunciation Assessment](https://arxiv.org/abs/2609.13694), 2026. Proposes ordered subphonetic states and optimal temporal transport; the LANGFENS experiment is a static-plan window adaptation.
- Geng et al., [Beyond Acoustic Sparsity and Linguistic Bias: A Prompt-Free Paradigm for MDD](https://arxiv.org/abs/2604.22133), 2026; [official IF-MDD repository](https://github.com/Secondtonumb/IF-MDD). Public CROTTC/IF code and corpus-specific bundles exist, but the bundled L2-ARCTIC checkpoint split provenance is not adequate for this TRAIN-only experiment. It was not used.

## Interpretation rules

1. Keep specialist target AP separate from Macro-3 Error AP. Do not impute I or unsupported classes.
2. A/B/C H-001 variants share the same substitution and insertion heads. Their insertion AP repeats the frozen baseline and is not evidence of a new insertion method.
3. DEV_SEARCH is development-exposed and supports exploratory findings only. One-seed changes are not repeatability evidence.
4. Intended-reference provenance is annotation-derived and its independence remains unverified.
