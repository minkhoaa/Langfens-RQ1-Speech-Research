# Falsification Criteria: Hypothesis H99

Hypothesis H99 will be declared **FALSIFIED** if on held-out `DEV_REPLICATION`:
1. Standalone Macro Precision falls below 60.00%.
2. Standalone Macro Recall falls below 60.00% (excessive smoothing blunting error sensitivity).
3. Standalone Weighted Utility falls below 0.4850.
4. False Warning Rate (FWR) fails to drop below 2.80 false alarms per utterance.
