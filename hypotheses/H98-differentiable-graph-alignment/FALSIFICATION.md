# Falsification Criteria: Hypothesis H98

Hypothesis H98 will be declared **FALSIFIED** if on held-out `DEV_REPLICATION`:
1. Standalone Macro F1 fails to exceed 0.6285 (inferior or identical to ADAE-Net EXP-94).
2. Standalone Weighted Utility falls below 0.4950.
3. False Warning Rate (FWR) exceeds 2.80 false alarms per utterance.
4. Expected Calibration Error (ECE) exceeds 0.0260.
